# Google Sheets の2シート構成への移行

## 最初に行うこと

1. スプレッドシートの「ファイル → コピーを作成」でバックアップする。
2. 従来の「日付・BP・SQ・DL・体重」の5列が入った**先頭タブは削除・移動しない**。移行前の開発プレビューはこのタブを参照する。
3. 新しいタブ **pr_records**、**body_weight** を作成する。タブ名とヘッダー名は以下のとおり正確に入力する。

## pr_records

| A: date | B: exercise | C: weight_kg |
| --- | --- | ---: |
| 2026/09/01 | BP | 110 |
| 2026/09/15 | BP | 115 |
| 2026/09/27 | DL | 170 |

- 1行目に見出し **date / exercise / weight_kg** を入力する。
- 1RM自己ベストを更新したときに、1種目ごとに1行追加する。
- exerciseには **BP・SQ・DL** の選択肢だけを用意し、その他の入力を拒否する。
- weight_kgは0より大きい数値のみを許可する。
- 同じ日付に異なる種目を記録してもよい。同じ日付・同じ種目は原則1件にする。

## body_weight

| A: date | B: weight_kg |
| --- | ---: |
| 2026/09/25 | 86.2 |
| 2026/09/26 | 85.8 |
| 2026/09/27 | 86.0 |

- 1行目に見出し **date / weight_kg** を入力する。
- 測定日に1行を追加する。通常は1日1回。体重だけの日も記録可能。
- weight_kgは0より大きい数値に制限する。

例示の値はダミーです。実測値に置き換えてください。

## 入力規則

Google Sheetsの「データ → データの入力規則」で以下を設定します。

| 範囲 | 入力規則 | 表示 |
| --- | --- | --- |
| pr_records!A2:A | 有効な日付 | yyyy/mm/dd |
| pr_records!B2:B | プルダウン：BP、SQ、DL | 選択式 |
| pr_records!C2:C | 0より大きい数値 | kg |
| body_weight!A2:A | 有効な日付 | yyyy/mm/dd |
| body_weight!B2:B | 0より大きい数値 | kg |

いずれも無効な入力は拒否する設定を推奨します。ヘッダーを固定し、列を追加する場合はコード側も更新してください。

## 既存データの移行方法

- 元の5列データを日付昇順に確認する。
- BP/SQ/DLそれぞれ、**それ以前の自己ベストを超えた記録だけ**を pr_records に移す。空欄や未更新は転記しない。
- 体重のある行は日付と値を body_weight に移す。1日1件に揃える。
- 手作業が多い場合は、リポジトリの scripts/migrate-legacy.gs を**任意で1回だけ**使用できます。Google Sheetsの「拡張機能 → Apps Script」に貼り付け、**SOURCE_SHEET_NAMEに現在のタブ名を設定**して migrateLegacyBig3 を実行してください。
- このスクリプトは新しい2タブが既に存在すると中止し、**上書きはしません**。手作業方式とスクリプト方式のどちらかを選択します。
- 処理結果はApps Scriptの実行ログに出力されます。転記したデータと警告を必ず照合してください。
- 元データは消さずに残してください。スクリプトは定期トリガーを設定しません。

## 画面での確認

developは、2タブのヘッダーが正しく、少なくとも一方に行があると新形式を利用します。それまでは先頭タブの旧形式へフォールバックし、画面に「旧形式」と表示します。**新2タブの転記を両方終えてから**プレビューを確認してください。片方だけ転記すると、その間の表示が不完全になります。

- [ ] 画面から「旧形式」の表示が消えている
- [ ] 各種目の最高1RM、Total、達成日が一致する
- [ ] 最新体重・測定日が一致する
- [ ] 7日平均が直近7暦日の実測値の平均になっている
- [ ] 7日を超える体重測定空白期間では、過去の体重比を表示しない
- [ ] データの警告が解消されている、または理由を確認している

**この照合が終わるまではmainへのマージを行わないでください。**

### 集計のルール

- 自己ベストは種目ごとの累積最大値。Totalは各種目のPB合計で、3種目が揃ってから算出。
- カードの体重比は歴代PB÷最新測定体重（体重の日付を併記）。
- 履歴の体重比は対象日に有効なPB÷同日または直前7日以内の体重。
- 7日平均は、対象日を含む直近7暦日の実測値だけを算術平均する（未測定日を補間しない）。
- ブラウザは読み取り専用。スプレッドシートの変更権限や秘密情報は持ちません。
