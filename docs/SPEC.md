# 画面・データ仕様

## 概要

1RM自己ベスト更新履歴と体重測定履歴を独立してGoogle Sheetsに保存し、ブラウザで集計・表示する読み取り専用ダッシュボードです。

## データモデル

| タブ | 1行目の列見出し | 記録する値 |
| --- | --- | --- |
| **pr_records** | date, exercise, weight_kg | BP/SQ/DLの1RM自己ベスト更新時に1行 |
| **body_weight** | date, weight_kg | 体重測定日ごとに1行 |

日付は日本の暦日（YYYY-MM-DD または YYYY/MM/DD）とし、重量はkgの正数です。種目はBP・SQ・DLに限定します。タブごとに記録頻度が異なって構いません。

## 取得とデータ検証

- gviz JSONをsheetパラメータを指定して2タブから取得します。
- ヘッダーを検査し、無効な日付・正数でない重量・種目の誤入力を警告とともに除外します。
- 同一日付・種目が重複する場合は高い重量を採用し、警告します。
- その時点のPR以下の記録は累積PRに反映せず、警告します。
- 同一日付の体重が重複する場合は最後の値を採用し、警告します。
- 両タブの取得とヘッダー検証を必須とし、不足・不正な構成では取得エラーと再試行を表示します。両方のタブが空の場合はデータなしとして扱います。
- ブラウザにはシートの閲覧権限だけが必要です。認証情報を埋め込まないでください。

## 計算のルール

- **自己ベスト**：各種目の1RM累積最大値。過去にさかのぼって新規記録を追加した場合も日付昇順に再計算。
- **達成日**：その種目の現在の自己ベストを更新した日付。
- **Total**：BP・SQ・DLの3種目すべてに有効な1RM自己ベストが記録された日から、各種目の歴代自己ベスト合計を表示します。それ以前はカード・履歴グラフ・体重比ともに値なし（`null`、画面では「—」）とし、途中の1種目・2種目の合算値は表示しません。同一日競技Totalではありません。
- **カードの体重比**：その種目の歴代最高1RM ÷ 最新の実測体重（体重の日付は別途表示）。
- **過去の体重比**：対象日当日または過去7日以内の最後の測定体重を分母とする。測定から7日超なら値はnull。
- **体重の7日平均**：測定日を含む過去7暦日（当日＋前6日）の実測値を平均。測定していない日を補間しない。
- **履歴**：PR更新日と体重測定日の時系列を結合して累積PBを表示。体重グラフは実測値と7日平均を表示。
- **表示期間**：6か月・1年・全期間。両タブの最終記録日を基準に絞り込む。
- **取得**：初回表示に取得し、失敗時は再試行。自動ポーリングは行わない。

## 表示

PCでは自己ベスト4カード・グラフ2列、小画面はカード2列・グラフ1列。達成日、最新体重、7日平均、データ検証警告を含みます。内訳バーと凡例は3種目すべての自己ベストが揃ってから表示します。



## Google Sheetsの入力規則

| 範囲 | 推奨する入力規則 |
| --- | --- |
| `pr_records!A2:A` | 日付（表示形式 `yyyy/mm/dd`） |
| `pr_records!B2:B` | `BP`・`SQ`・`DL` のプルダウン |
| `pr_records!C2:C` | 0より大きい数値（kg） |
| `body_weight!A2:A` | 日付（表示形式 `yyyy/mm/dd`） |
| `body_weight!B2:B` | 0より大きい数値（kg） |

1RM自己ベストを更新したときだけ `pr_records` に1行追加し、体重は測定した日ごとに記録します。同一日付・種目のPRや同日の体重重複を避け、入力規則は「無効な入力を拒否する」に設定することを推奨します。

## 不正データの通知

読み込みは成功していても、無効な日付・種目・重量、同日の重複、自己ベスト以下の記録については、画面上部の **「データに関するお知らせ（件数）」** に表示します。詳細を開くと最初の15件を確認できます。不正なレコードは、除外するか明示した規則で処理し、元のスプレッドシートは変更しません。
